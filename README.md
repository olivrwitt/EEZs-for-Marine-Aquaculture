# Identifying EEZ Regions Suitable for Marine Aquaculture
### Description
This repository contains data and code for homework assignment for EDS223 Geospatial, which focuses on identifying Pacific Exclusive Economic Zones best suited for marine aquaculture.  The code uses oysters and red abalone as example species, although it is written as a function that is generalizable to any species with reasonable aquaculture potential.

### Contents
All code, comments, and outputs are in "aquaculture_analysis.qmd".
The "data" folder contains all necessary data on sea surface temperatures, depth, and geography of USA West Coast EEZs.

### Data Access
Data is housed locally in the repository.
Sea surface temperature (SST) data is sourced from NOAA's Daily Global 5km Satellite Sea Surface Temperature Anomaly (https://coralreefwatch.noaa.gov/product/5km/index_5km_ssta.php).
Depth data comes from GEBCO, General Bathymetric Chart of the Oceans (https://www.gebco.net/data-products/gridded-bathymetry-data#area).
EEZ boundries come from Marineregions.org (https://www.marineregions.org/eez.php).
